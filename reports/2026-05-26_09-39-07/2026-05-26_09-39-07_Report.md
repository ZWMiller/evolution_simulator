# Identical habitats produce clustering around one optimum rather than directional divergence, but drift still creates inter-lineage variance

---

## Experiment Summary

**Config:** `identical_habitat_control.toml` (copy in this folder)
**Log dir:** `simulation_logs/2026-05-26_09-39-07/`
**Run date:** 2026-05-26
**Comparison run:** `reports/2026-05-25_16-09-11/` (parallel divergence — five distinct habitat types)

Five **identical** Forest habitats were each seeded with the **same three founding species** using `mirror_founding_population = true` — the same founding genomes as the parallel divergence run, with fresh per-creature noise and no habitat bias. No connections, no migration. The goal was to test the hypothesis that identical selection pressure produces convergent rather than divergent traits, using the divergence run as the controlled contrast.

*jade dweller* (meta=1.567, fec=6.851), *mystic striker* (meta=1.812, fec=6.613), *bristled climber* (meta=1.847, fec=5.402)

## Report Summary

**Why this was interesting:** The previous parallel divergence run showed large, directional trait splits across Forest, Plains, and Wetlands — but those habitats apply different selection vectors. This run removes the confound: all five habitats are geometrically identical, so any remaining variation at the end must come from genetic drift or random founder effects within each habitat, not from selection pressure differences.

**What was found:**
- All five habitats survived (no extinctions), producing six species at week 30,000. Competitive exclusion still eliminated all but one dominant species per habitat by the end.
- 225 speciation events across 30,000 weeks — more than the divergence run's 110, because all five habitats remained active throughout.
- Trait spreads at week 30,000 are **similar in magnitude** to the divergence run (~0.23 for metabolism, ~54 weeks for max lifespan), but the **pattern is fundamentally different**: four of five species cluster tightly around the Forest selection optimum, while the divergence run shows a clean bimodal split driven by habitat type.
- One lineage (*deep glider*, forest_4) drifted to metabolism 1.57 — well outside the cluster of four others at 1.33–1.36. This is the same range as the Plains and Wetlands species in the divergence run, but without any habitat driver. Pure drift.
- The *fractured borer* anagenesis cascade (weeks 8450–8900, 4 events) recurs in this run at almost the same generation window as in the divergence run (weeks 6050–6950, 6 events). Same founding genome, same Forest habitat — this implicates the Forest habitat vector geometry as the proximate cause of those cascades, not the divergence run's multi-habitat dynamics.

**Takeaway:** Removing habitat-type differences does suppress directional divergence. The majority of lineages converge on the Forest selection optimum as predicted. However, genetic drift produces enough inter-lineage variance that raw trait spread remains comparable in magnitude to the multi-habitat divergence run. The difference is in signal shape: the divergence run produces a habitat-correlated bimodal distribution; the control run produces a tight cluster with occasional drift outliers.

## Report

### Setup and contrast with parallel divergence run

The parallel divergence run ([report](../../reports/2026-05-25_16-09-11/2026-05-25_16-09-11_Report.md)) showed that five isolated habitats with different selection vectors diverge strongly in mechanically-active traits, with Forest, Plains, and Wetlands each producing a distinct species phenotype. Desert and Tundra went extinct because random founding genomes were too misaligned to survive harsh conditions.

This run replaces all five habitats with an identical Forest configuration (all `seed=1`, same CENTER vector + same per-instance noise). Everything else is held constant: same founding genomes (`seed=7`, `mirror_founding_population=true`), same speciation parameters, same run length. This isolates the effect of habitat-type selection from everything else.

### Extinction

None. All five Forest habitats sustained populations throughout the 30,000-week run. The Forest habitat vector is close enough to random gene configurations that populations survived without adaptation headstarts — consistent with the divergence run, where Forest was the only habitat that never risked early extinction.

**Total:** 225 confirmed speciation events (217 cladogenesis, 8 anagenesis), vs. 110 events in the divergence run. The higher total is expected: the divergence run lost two habitats early, reducing active lineages by 40%.

**Failed attempts:** 2,068 (89% failure rate through the two-stage candidate gate)
**Hybridization events:** 7,626 across the full run

First speciation: week 766 (*skeletal creeper* from *jade dweller*), one week earlier than the divergence run's week 867.

### Anagenesis events

Eight in-place lineage transformations occurred across three clusters:

**Cluster 1 — *fractured borer* cascade (weeks 8,450–8,900):**
fractured borer → *crystalline rooter* → *primal feeder* → *dark monitor* → *crystalline apex*

Four transformations in 450 weeks. This is the same founding lineage (*jade dweller* → *fractured borer*) that produced a cascade in the parallel divergence run at weeks 6,050–6,950 (6 events in 900 weeks). Both runs share the same founding genome and the same Forest habitat vector. The recurrence — in timing, in lineage, and in habitat — strongly implicates the Forest habitat vector geometry as the cause. Whatever gene-space direction the Forest optimum drives phenotype evolution toward, the *fractured borer* lineage crosses the anagenesis threshold repeatedly as it chases that optimum.

Note: this cluster ran with pre-fix code (the cascade re-fire bug was not yet applied). The 150-week intervals between events are the signature of that bug.

**Cluster 2 — isolated event (week 17,700):**
*fierce spawner* → *vivid planter* — a single transformation with no cascade follow-on.

**Cluster 3 — *calcified seeker* cascade (weeks 23,250–23,800):**
*calcified seeker* → *ancient wraith*, *deep skulker*, *venomous shaker* — three transformations in 550 weeks.

### Trait convergence analysis

**Hypothesis going in:** Identical habitats → stronger convergence (smaller spreads) than multi-habitat divergence run.

**What the data shows:**

| Trait | Control spread | Divergence spread | Founding spread | Pattern |
|---|---|---|---|---|
| Metabolism (0.5–2.0) | **0.237** | 0.227 | 0.280 | Nearly identical magnitude; pattern differs |
| Water efficiency (0–1) | **0.156** | 0.068 | — | Control has *more* spread |
| Max lifespan (40–400 wk) | **54.6 wk** | 52.3 wk | — | Nearly identical |
| Fecundity (1–8) | **0.367** | 0.109 | 1.449 | Control compressed from founding; divergence more so |

The hypothesis is **partially confirmed but nuanced**: identical habitats do eliminate directional, habitat-correlated divergence, but they do not eliminate spread. Drift alone can maintain variance comparable in magnitude to full multi-habitat selection.

#### The critical difference: pattern, not magnitude

The divergence run's metabolism distribution is bimodal and habitat-correlated:
- Forest (*blazing swimmer*): **1.380** — energy-conservative
- Plains (*ochre chaser*): **1.603** — high-throughput
- Wetlands (*wandering caller*): **1.607** — high-throughput

The control run's metabolism distribution is a tight cluster plus one outlier:
- forest_3, forest_5, forest_2, forest_1: **1.332–1.355** — all near the Forest optimum
- forest_4 (*deep glider*): **1.569** — a drift outlier

Four of five species have converged to within 0.023 of each other on metabolism — directly on the Forest selection optimum from the divergence run (1.38). The fifth (*deep glider*) sits at 1.57, in the range typical for Plains and Wetlands species in the divergence run, despite experiencing identical selection pressure to its Forest neighbors.

This *deep glider* outlier is informative: it demonstrates that drift can mimic the signature of a different selective environment. Without the parallel divergence run as a reference, a naive observer could mistake *deep glider*'s metabolism value as habitat-adapted to a high-resource environment.

#### Water efficiency anomaly

Water efficiency shows more spread in the control run (0.156) than the divergence run (0.068). This may reflect that all five lineages are exploring the same gene space in different random directions — without distinct habitat vectors pulling each lineage toward a different water-efficiency optimum, the trait follows drift more freely. It is also possible that the identical habitat vector creates a flatter fitness landscape along the water-efficiency axis, reducing selection pressure to align on one value.

### Fecundity convergence

The founding fecundity range was 5.402–6.851 (a spread of 1.449). At week 30,000, the control run range is 6.960–7.327 (spread 0.367). Two things happened simultaneously:

1. All lineages moved toward higher fecundity — the Forest environment rewards reproductive throughput in a stable, resource-accessible habitat.
2. The spread compressed by 75% — lineages that started with lower fecundity (*bristled climber* at 5.4) were selected toward the optimum and converged.

The divergence run shows similar convergence of fecundity across its three surviving habitats (range 6.945–7.053), with slightly more compression. Both runs converge on roughly the same absolute fecundity level (~7.0–7.3), suggesting this is less a habitat-specific optimum and more a general selection pressure from the gene-habitat geometry.

### Competitive exclusion under identical selection

One dominant species per habitat occurred in both runs. In the divergence run, each habitat's winner was shaped by the habitat's specific selection vector. In the control run, all five habitats ran the same selection pressure — yet still produced distinct dominant species with some trait differences. Competitive exclusion + reproductive isolation (identical habitat but no migration between habitats) was sufficient to generate species differentiation. This confirms that speciation in this model does not require different selection environments; isolation alone creates divergence given enough time.

### Open questions from this run

1. *Deep glider* (forest_4, metabolism 1.57) is a clear drift outlier. Would a much longer run (100,000+ weeks) pull it back toward the Forest cluster, or does drift permanently displace isolated lineages?
2. The *fractured borer* anagenesis cascade recurs in the same lineage, same habitat, similar timing across both runs. What exactly in the Forest habitat vector geometry creates this repeated threshold-crossing? Running the Forest habitat in isolation from different founding seeds would test whether this is seed-specific or a geometric property of that habitat type.
3. Water efficiency shows *more* spread in the identical-habitat run. Is this because the identical selection vector creates a degenerate (flat) fitness landscape along the water-efficiency axis, allowing drift to dominate?
4. None of the three founding species survived to week 30,000 in either run. Is competitive exclusion on the same founding-species scale inevitable with these parameters, or does it depend on initial population size?
